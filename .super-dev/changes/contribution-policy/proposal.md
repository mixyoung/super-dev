# 固定 Super Dev 演进方向与贡献入口

2026-09-06 用户认可“方向固定、问题驱动、证据准入、版本化采用”的方法，明确要求固定下来，让后续模型与开发者看到并遵守。

本批仅完善仓库维护制度：一个权威贡献准则、现有入口链接、知识维护/评审说明、PR 模板、CODEOWNERS、8 个稳定行为案例，以及只读贡献记录检查接入现有 CI。不是普通用户的新流程，不更改产品 Skill 或阶段运行程序。

验收：入口可发现；无记录/范围缺失/结构错误会失败；合法记录及普通无关修订可通过；无效 Git 基线失败；删除与改名不漏报；不依靠“最近 change”选择；跨平台命令不写用户配置；已有 U7—U14 工作不改写。机械通过不能代表语义正确或维护者批准。

远端主线保护目前未开启。本批不执行提交、推送、修改仓库设置或添加实际审查者；CODEOWNERS 使用已核实的当前仓库所有者 @mixyoung。启用远端强制要求需另行确认，尤其单维护者不能批准自己的 PR。
