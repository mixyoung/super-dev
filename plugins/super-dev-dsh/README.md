# Super Dev 的 DSH 可选伴生插件

本地组合包 `@local/super-dev-dsh`，以官方 DeepSeek Harness `0.2.2-rc.3` 为接入目标。它增加一个原生查询工具 `super_dev_status`，不替代 Super Dev 核心或默认项目接入。使用工具时，DSH 用自己的通用工具卡显示结果，不增加侧栏、页面或新的斜杠命令。

## 什么时候用

在 DSH 中打开已经绑定的本地项目，照常用原生菜单的 `/super-dev` 或 `/super-dev-seeai`。需要检查进度时，可以在原会话问「查看 Super Dev 的项目接入和当前任务状态」。宿主可用 `super_dev_status` 查询：

- 当前项目中的两项 DSH 专属技能是否缺失、修改或无法读取；检查的是项目内的定义，不把同名共享技能当成已接入。
- `AGENTS.local.md` 中的 DSH 托管块是否符合已有接入合同。
- 当前已记录的工作项、标准或 SEEAI 模式、阶段，以及文档、预览或继续当前任务的提示。没有可核验的主状态时不会读取旧快照来替代。

**保留 DSH 内置的「工作区指令加载（`agent-instructions`）」**。它负责实际注入项目规则；本插件不加载工作区指令，不要求与它互斥。发现文件不代表规则已经进入当前会话，也不代表官方 A12 回退安全或完整桌面流程已通过。工具不开始、推进、恢复或确认任何任务，不改项目文件或 Core 状态。DSH 自己仍可按正常规则记录工具调用。

## 在选定配置档启用

1. 保留既有 Super Dev 项目接入。先准备含 `super_dev.integrations.dsh_plugin_snapshot` 的同版 Super Dev 核心；插件不会自动安装它。
2. 用 DSH 官方本地组合包管理入口选择这个包的本地目录（`plugin_manager` 的 `install_bundle`，目标是包目录的绝对路径）。只在你明确选择的配置档安装；不会自动写入默认配置或所有项目。DSH 的包管理器可能启动包安装流程，本地目标不保证脱离网络，请先在隔离配置验证。
3. 在该配置档的用户补丁中为 `super-dev-dsh-companion` 配置**可信、已安装上述核心的 Python 绝对路径**。解释器不能来自正在查询的项目，也不能使用脚本、相对路径或临时从项目继承的环境。下面仅为配置占位示例：

```yaml
- id: super-dev-dsh-companion
  config:
    pythonExecutable: 'C:\path\to\trusted\python.exe'
```

没有解释器配置、项目未绑定、工作目录越界或状态不兼容时，查询会显示受阻（`BLOCKED`），不会运行其他程序来补救。工具只用固定参数启动这个 Core 查询模块，有限时与输出长度，不扫描认证配置，不连接模型。命令结果只含项目接入状态与必要的工作项字段，不返回规则、技能或日志正文。

## 停用或移除

在同一配置档停用本地组合包（`set_bundle`），会停止启用但保留依赖；移除组合包（`remove_bundle`）才删除安装关系。如果 DSH 要求重启，重启后再确认该插件和工具已不再可用。不要关掉 `agent-instructions`。移除伴生插件不会移除项目原有规则和双技能；完全卸载 Super Dev 项目接入仍使用既有卸载流程。没有由本插件留下的来源拦截或隐藏技能。
