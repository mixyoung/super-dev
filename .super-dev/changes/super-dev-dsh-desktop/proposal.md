# Proposal

## DeepSeek Harness 桌面版正式适配

## Description
按已确认三文档实现专属双技能、DSH限定项目规则、完整装卸诊断恢复及十四项验收。最新环境设计已确认，但用户明确要求目前不使用虚拟机、模型API需要时再询问。当前继续项目内无模型准备：形成冻结rc.3同版原生副本，保留原混合版本与163项历史证据，重跑原生来源/预算/恢复链，不放宽验收。

批准依据：[修订文档确认与执行限制](../../../output/dsh-host-research/environment-design-2026-11-16/DOCS-CONFIRMATION.md)。

## Motivation
项目接入和装卸缺陷已有代码回归，真实完整桌面流程尚未完成。官方 rc.5 与新观测的 0.2.2-rc.1 均存在规则预算省略/同名回退的机制缺口，需要隔离原型验证可行修复，不再靠重复菜单测试或缩短提示词冒充解决。

## Impact
保留既有 DSH 接入和旧 Claude/Codex 生成字节。原生修改只允许在已批准的原型目录，不改现用 DSH，不新增模型端点或第二流程状态机；原型通过不能改称官方版完成，不运行真实模型或发布。
