## 1. 决策结论

我们决定**全面吸收 Grill with Docs 的极限需求追问、设计单选决策与原地写回回读机制，将其深度固化到 Super Dev 的 PM 和 ARCHITECT 角色行为中**；**不将该方法作为无边界的过度推演工具，在用户明确确认后立即停止追问进入下一阶段**。
