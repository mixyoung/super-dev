## 3. 官方 `skills/oil-tone/SKILL.md` 核心原则摘录 (Core Rules Excerpt)

以下为上游原技能定义中提取的核心表达规则关键句：

1. **信息顺序**：
   > “先告诉读者结论和对他有什么影响，再展开背后的原因或机制。不要让读者读完全文才发现重点在最后一段。”

2. **完整主体与状态因果**：
   > “句意关系必须完整。动作谁发起的、作用对象是谁、前后状态变化是什么，必须交待清楚。避免只有抽象动作没有主宾的虚浮表达。”

3. **保留自然的虚词**：
   > “不要机械化地全量删除‘的’和‘了’。符合中文口语与工程技术语感的助词应当自然保留，生硬删词只会让技术文档读起来像未经校对的机器翻译。”

4. **复核方法**：
   > “大声朗读或按正常语速默读。如果在读的过程中觉得喘不上气、或者脑海中无法立刻建立对应的画面与操作认知，则说明该句子存在冗余或抽象堆砌。”
