## Architecture Impact

- 在原注册/目录/CLI/诊断/使用/恢复/运行报告消费者中新增 `deepseek-harness`；仅增加 `dsh` 别名。保持现有类别，解耦原生技能 slash 与命令文件支持。
- 唯一模板增加 DSH 标准/SEEAI 分支及正确前置元数据；项目 `.dsh/skills` 与 `AGENTS.local.md` 托管块通过现有安装清单维护。
- 扩展可注入用户目录以处理 DSH home，旧构造兼容；默认不访问真实用户目录。
- 修复本轮装卸实际调用路径的字节保护，保留用户 BOM、换行、空白、其他宿主块和修改后的技能；共享 helper 改动须回归其真实旧消费者。
- 不增加产品 HTTP API、网页、认证桥、第二流程状态机或用户启动门禁。知识/通用语言规则保持原样。
- 原混合版本副本、策略模块和旧证据保持原路径；同一原型根内新增 `source-rc3/` 存放从冻结ASAR读取的六个同版原生模块与包元数据。测试模式显式选择此目录，策略/预算模块复用唯一实现；不是新工作树或运行环境。
- 每个同版模块及其基础源码/包版本均绑定rc.3，运行依赖仍来自已核验冻结副本；原rc.1/mixed回执不改写。同版模块通过不等于已构建完整DSH桌面，也不改变正式支持版本或发布结论。

## Ownership and sequence

- `PLACEMENT_OWNER`：当前 Claude Code 主会话，已安排当前分支/工作区；不创建新工作树。
- `PRODUCTION_WRITER`：当前主会话，依据用户明确选择“由本会话接任（推荐）”。原 Codex 未启动，无并行写入者；仅写已批准的隔离原型及治理记录，不修改既有生产文件。改派回执见 output/dsh-host-research/architecture-revision-2026-11-13/WRITER-ASSIGNMENT.md。
- `MAY_SPAWN_SUBWORKERS=no`。执行者不得下派、另建协调器、分支或工作树，不提交、推送、开 PR、发布或部署。
- 只读评审可在固定差异上进行；主会话接受结果，编程修复优先送回原写入者。
- Spec/计划校验后按现有无 UI 适用路径进入实现；适用性不等于批准一个不存在的预览，也不免除 A02 的真实 UI 样例测试。
- 历史3.*～7.*证据按原范围保留。当前执行8.1确认/规格、8.2同版副本、8.3离线回归、8.4准入说明；不新建流程状态。真实桌面5.2～5.4和交付6.1仍未完成。
- 当前不创建/启动虚拟机，不启动Docker/WSL或Windows Sandbox。此限制暂缓设计中的虚拟机路线，不降低隔离或原验收。需要真实模型时再询问用户提供专用API与运行范围；此刻不读认证、不发请求。

## Risks & Mitigations

| 风险 | 处理与停止条件 |
| --- | --- |
| 原生 slash 与旧命令文件假设耦合 | 查实际消费者，最小解耦；不填假路径来满足断言。 |
| 通用区块文本读写损坏字节 | 保留原失败样例和红灯，测真实安装/卸载；损坏标记保守保留，绝不使用 strip 清理用户区。 |
| 用户技能被更新/卸载覆盖 | 用既有归属/摘要机制区分未改内容与用户修改，更新和删除均测试反例。 |
| 部分安装失败留下混合状态 | 故障注入后复用原入口重跑，不能把异常吞成成功；不做越权破坏性回滚。 |
| 规则预算或卸载后共享回退不安全 | 分别观察实际规则、技能来源、操作和状态；A12 失败即阻断完整支持，不留永久块或改 Codex。 |
| active/armed 自动续跑越门 | 原型拒绝、预算耗尽或强制停止均不能代替自然等待；自动提示不是批准，现用目标/预设不改。 |
| 环境和认证权限不足 | 先完成其余安全工作；明确未验证与阻断，不读取更多配置或安装组件。 |
| 旧宿主内容漂移 | 修改前后同输入四渲染字节比较，保留集合/数量及实际消费者测试。 |
| 继承旧流程派生字段 | Core 当前已绑定 Spec；阶段推进只经现有 Core，并核对工作项及有效确认。旧发布事实不是本次交付证据，不据其宣称发布。 |
