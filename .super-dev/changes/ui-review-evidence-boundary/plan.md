# 实施计划：UI 验收证据边界整改

## Context

### 执行入口

- 用户已明确确认三文档和独立工作树。沿用当前正式工作项，不修改原 DSH 工作项。
- 本变更不新增产品页面，仓库前端阶段不适用；真实浏览器和视觉行为另用测试项目验证。目标 UI 项目的预览门不变。

## 顺序

1. 退出 Pillow 和像素审美判断，保留合法图片验证夹具与原失败基线。
2. 分离源码探测、真实浏览器和图片输入的证据生产与消费；明确识别旧报告、无图片能力或无法核对输入的情况。
3. 更新质量、就绪、证据包、已有 UI API 和宿主默认指导。宿主生成规则只由仓库唯一模板及既有同步机制维护。
4. 跑针对性回归、项目检查、构建和干净安装；实际核验可取得的图像链路。任何不适用或未验证项均保留，不走发布或部署。

## 风险与回退

- 旧运行报告由源码探测生成，不能凭其中 `passed` 断定运行；保留原静态工程规则，独立校验宿主运行证据。
- 报告输出不可变成其自身的依赖；写入前保持捕获时的身份，不重新给旧图片盖当前摘要。
- 回退限本工作项差异，保留原始记录和文档确认；不迁移旧像素判断为真正看图。
